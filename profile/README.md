# WEP Global Tech

WEP Global Tech is an Atlanta-area technology company founded by Elroy “Roy” Phillip. This GitHub organization hosts public examples of infrastructure engineering, systems administration, monitoring, and cloud automation work.

Roy brings 26+ years of experience supporting mission-critical enterprise and broadcast systems, including Windows Server, VMware, Active Directory, network operations, incident response, and disaster recovery. He is an AWS Certified Cloud Practitioner and a U.S. Marine Corps veteran.

- [AWS infrastructure with Terraform](https://github.com/WEPGT/tcbc-terraform-codex-aws) — A documented two-Availability-Zone VPC foundation with public and private subnets, routing, consistent tags, and a deployment record.
- [Linux monitoring stack](https://github.com/WEPGT/linux-monitoring-stack) — Prometheus, Node Exporter, Alertmanager, and Grafana configuration with installation guidance and verification screenshots.
